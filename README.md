HM-CertChain is a blockchain-based hierarchical certificate management and secure CA migration framework built on Hyperledger Fabric 2.2. It introduces a double-hash block structure for efficient certificate queries, a Hierarchical Authorization Chameleon Hash (HOA-CH) mechanism for controlled data modification, and an atomic CA migration protocol based on hash time-locked smart contracts. HM-CertChain enables secure trust relationship transfers while preserving certificate validity, reducing migration overhead, and supporting scalable, transparent, and auditable PKI management.
